## 叙事风格

### 叙事视角
- 必须使用第三人称限知视角，POV 锁定主角许七安，禁止跳入其他角色的内心。
- 主角的怀疑、推理、吐槽、腹诽必须以内心独白外化（`心说` / `心里` / `腹诽`），禁止旁白代答主角在想什么。
- 其他角色只通过动作、神态、台词被"看见"，禁止直接写他们的内心；若必须交代，只能借主角的观察与推断转述。
- 探案复盘（主角在大脑里还原案发经过）可以短暂"灵魂出窍"式全知俯瞰，但必须用"他感觉自己进入某种状态/时光仿佛倒流"这样的标记明确框定，且复盘结束立刻拉回现实动作。

### 叙事节奏
- 每一章必须包含至少 2 个事件推进点（线索发现 / 关系变化 / 危机升级 / 谜题破解），禁止连续 3 段纯描写或纯设定而无事件。
- 对话段落不超过 3 轮就必须插入动作、神态或心理，禁止无间断对话流。
- 紧张场景（探案对峙 / 战斗 / 朝堂交锋）用短句、断句、拟声词加速；舒缓场景（日常、家庭、勾栏听曲）允许中长句铺陈。
- 每章结尾必须留钩子（一个反转 / 一条新线索 / 一句反常的话 / 一个"不对劲"的发现），禁止以平静收束结尾。

### 叙事手法
- 主线顺叙推进，用"一个案件 → 牵扯出更大的局 → 再破一案 → 又牵出更大的局"的**串案式结构**滚雪球，禁止孤立的单元案。
- 长线伏笔（身世、地书碎片、气运、幕后大棋）可以跨数百章，但必须前期留可查证线索（一句反常的话、一个不合常理的细节），禁止凭空降神。
- 悬念信息碎片化释放：靠卷宗、口供、遗书、纸条、他人对话片段层层剥洋葱，主角实时推理并纠正自己的判断。

### 时间线处理
- 主线严格线性推进，时间流逝用季节、气候、节气等细节标记（"十一月底，京都的气温最冷应该有零下"）。
- 主角对"前世现代"的回忆用内心吐槽插入，限制在 1~2 句内，禁止大段闪回。
- 复盘案发经过时允许"时间倒流"式重现，但必须用"他脑海里复盘着……"的标记明确框定，结束即拉回现实。

## 情节构建

### 开篇套路
- 第一章必须"绝境开局"：主角穿越即入狱、性命攸关（许七安醒来在牢里，三日流放边陲），用生存危机逼出主角的第一手牌（现代刑侦能力）。
- 开篇禁止大段世界观设定；大奉王朝、修炼体系、势力分布等信息必须随主角破案、入局逐步解锁。
- 开篇必须建立的读者认知：① 主角的现代身份与核心能力（刑侦推理）；② 核心矛盾（税银案 / 全家连坐）；③ 主角的隐藏底牌（气运 / 现代知识）。

### 高潮设计
- 高潮必须满足：① 至少两方势力对撞（朝堂 / 江湖 / 佛门 / 妖族 / 巫神教）；② 主角陷入绝境后翻盘；③ 翻盘靠"临场推理 / 预留后手 / 气运加持"，禁止机械降神。
- 高潮前必须有铺垫（早埋的线索、已建立的人脉、前文提过的知识），铺垫内容必须可回头查证。
- 反派败因必须合理：布局深远的大棋手最终被主角以更早的一手或更硬的逻辑反杀，禁止反派智商下线。
- 弑君/大决战用"多方反应蒙太奇"（大奉独有）：重大事件（弑君）后必须切多个角色的反应镜头——太子"流下激动的泪水"、王首辅"快意悲伤感慨"、魏党"朝东北作揖"、怀庆"心底松口气"、李妙真"青春结束了"、黑莲"气急败坏"、监正"布局揭底"。用不同角色的反应烘托历史重量，禁止只写主角一个人的视角。

### 收尾习惯
- 每章最后一段必须含钩子或反转，禁止"欲知后事如何"式套话。
- 案件收尾必须"揭底"：主角当众把"疑点 → 假设 → 验证 → 结论"一条条摊开，让旁观者（府尹 / 大儒 / 群臣）由不信到震惊。
- 全书收束：身世闭环 + 阵营胜负落定 + 大团圆（庆功宴式群像收尾），并落回情感余韵（后宫修罗场的调侃收尾），可附"作者的话"交代创作心路。

### 情节推进方式
- 事件驱动 + 对话驱动双轮，推理必须外化给读者，禁止幕后解谜。
- 禁止靠纯巧合推进；禁止反派主动送人头；禁止配角长篇解说替主角解密。
- 每 3~5 章必须有一次性推进：案件突破 / 实力品级提升 / 关系变化 / 势力归属 / 身份揭示其一。

### 爽点设计
- **科学破案**：主角用现代知识（质量换算、化学、痕迹学）破解古代悬案，破解瞬间必须有古人的震惊反应托底。
- **诗词装逼**：主角（或借他人之口）搬出后世名诗碾压大儒，爽点落在旁观者的震惊、嫉妒、抢着收徒上，禁止主角自夸。
- **打脸权贵**：被轻视（衙役 / 阶下囚身份）后必须当章或下一章内反击，反击时必须有旁观者"鸡皮疙瘩起了一身"式的震惊。
- **朝堂翻盘（大奉独有）**：最高级的打脸是"金銮殿当众翻盘"——反派（礼部尚书）当众挑事，主角方早有准备、当众甩出铁证（人证已在宫城外），"刹那间朝堂上一片寂静"。公式：**反派跳出来发难 → 主角方沉默蓄势 → 当众抛出致命证据 → 满朝寂静**，禁止主角私下小打小闹式翻盘。
- **资质评级装逼（大奉独有）**：主角不靠装弱，靠"硬资质"碾压制造震惊——资质评级（甲上 / 甲 / 乙）是量化的装逼工具，主角凭"甲上资质 / 一周天寻出气感 / 炼神境元神强度"让高层失态（面瘫杨砚震惊、阴柔同僚"不可能"、六名金锣齐声抢人）。核心公式：**抛出客观资质数据 → 权威人物先怀疑后震惊 → 高层竞相拉拢**，禁止主角自夸"我很强"。
- **气运躺赢**：运气好到"走路捡钱"，但必须搭配主角的脑子，禁止纯靠运气无脑过局。
- **多女主福利**：写女性用"外貌 + 媚态 + 生理反应"三段式留白，落在神态氛围，点到即止。
- **擦边文雅化（大奉独有）**：古典美而非直白性感——`倾城`（68）、`倾国`（57）、`风情万种`（16）、`国色天香`（22），用成语写美，禁止"前凸后翘"式现代直白形容。
- **赠诗杀人诛心（大奉独有）**：抄诗不是为了装逼，是为了诛心——反派倒台后主角追上去赠诗"人皆养子望聪明，我被聪明误一生。惟愿孩儿愚且鲁，无灾无难到公卿"（讽刺权贵愚钝才能善终）。抄诗装逼的最高形态是"借诗诛心"，禁止只停留在"惊才绝艳"的表面。
- **身份错位高潮（大奉独有）**：主角被误认成"大人物"（古墓干尸跪拜"主公"），靠"拗人设"稳住场面（"做的不错""你在教我做事？"），最后身份揭破危机爆发。写身份错位靠"主角心虚硬撑 + 旁人震惊 + 濒临穿帮的张力"，禁止主角直接点破或怯场露馅。
- 爽点间隔：连续 3 章无爽点时，下一章必须安排一个（吐槽 / 打脸 / 抄诗 / 福利 / 反转其一）。

## 人物塑造

### 主角设定
- 主角许七安（字宁宴）：现代警察穿越，刑侦破案高手，风流好色但有底线，内心正义、不畏强权，爱推理、爱吐槽、爱扮猪吃虎，成长弧线从"棋子"到"棋手"。
- 遇到谜题 / 危机时必须先在心里吐槽 + 逐条推理，禁止面对谜题直接"灵光一现"。
- 遇到女性撩拨时必须嘴上风流、心里腹诽、手上点到即止，禁止正人君子式的拒绝，也禁止露骨上钩（他"许白嫖"的花名是调侃，不是真无底线）。
- 主角禁止出现：无理由的圣母心、面对敌人废话连篇、明知陷阱还往里跳、为了女人不顾大局。
- 金手指：① 现代科学知识（刑侦 / 化学 / 物理）；② 后世诗词（抄诗装逼）；③ 气运（身负大奉半数国运，运气极好）；④ 地书碎片（神识聊天群情报网）。使用限制：气运有代价与因果，地书碎片有保密规则，禁止无限开挂。

### 配角塑造
- 每个有名配角必须有"说话标记"或独特行为习惯（二叔许平志的粗坯、堂弟许新年的嘴强王者、婶婶的泼辣、妹妹许铃音的愚钝贪吃、监正的玄机莫测），一开口就能辨人。
- 配角至少承担一个功能（推动情节 / 提供信息 / 制造冲突 / 情感张力 / 提供笑点），禁止纯工具人。
- 女性群像用"类型 + 反差"立人设（清冷仙子洛玉衡、明艳长公主怀庆、俏皮临安、风情慕南栀各具一格），禁止所有女性一个模子。
- 女性武力反差（大奉独有）：女性角色不只有媚态，还要有武力或反差的"硬面"——慕南栀御雷诀召天雷（凛然女战神）、丽娜一巴掌拍碎脑袋（暴力南疆少女）、李妙真飞剑御敌（江湖女侠）。写女性立人设时，媚态与武力必须二选一或兼有，禁止纯花瓶。
- 反派群像要有"人物弧光"：前期是主角的靠山（监正 / 魏渊），后期可能反转，禁止脸谱化。
- 许新年"中二文人"喜剧（大奉独有）：傲娇读书人堂弟许新年，自诩天才、写诀别诗"天不生我许新年，大奉万古如长夜"准备悬梁，结果家人回来"觉得自己还是死迟了一步"。写傲娇文人靠"自命不凡 + 现实打脸"的反差，禁止把读书人写成一味酸腐。
- 许铃音"愚钝"人设的反转（大奉独有）：妹妹许铃音愚钝贪吃，却因"脑子里只有吃、心无杂念"攫取蛊神之力成为"史书上没记载的天才"，愚钝成天赋。写"缺点变天赋"的反转时，缺点必须始终一致（贪吃→专注力），禁止凭空洗白。

### 反派设计
- 反派必须是有能力威胁主角的大棋手：算无遗策、布局深远、计划有逻辑链条。
- 反派动机必须有明确利益驱动（攫取气运 / 维持统治 / 清除变量），禁止"纯粹的恶"。
- 反派必须在主角成长前占据优势，主角翻盘靠自身推理、预留后手或气运加持，禁止反派降智送死。
- 反派视角的权谋推演（大奉独有）：高智商反派要"站在主角阵营角度算人心"——反派分析"小皇帝守成有余魄力不足、许七安宁折不弯、两人利益不同必离心离德"，设计"议和之计一箭双雕"（成则要粮要钱，败则让主角与皇帝离心）。写反派谋略必须"攻心为上、算对手的内部分裂"，禁止反派只会喊打喊杀。
- 允许"亦敌亦友"的灰色角色（监正、魏渊），他们与主角的关系随立场变化推进，禁止非黑即白。

### 人物关系构建
- 新角色登场后 3 章内必须与主角建立明确关系（敌 / 友 / 中立 / 暧昧）。
- 关系变化必须有事件驱动；男女关系靠"风流撩拨 + 生死互助"升温，后宫线各女性与主角的羁绊必须有独立事件支撑，禁止无铺垫的突然动心。
- 家庭关系靠代际反差与市井烟火气（婶婶泼辣、二叔粗坯、妹妹愚钝贪吃）立住，禁止家庭线工具化。
- 后宫修罗场喜剧化（大奉独有）：多女主线不写苦情撕逼，写"忙不过来的喜剧"——主角写备忘录全是约会安排（临安 / 未亡人 / 怀庆 / 李妙真 / 丽娜），"我的正事呢？我要查的案子呢？"划掉改成"我需要一本《罗大师时间管理学》"。后宫是喜剧 + 自嘲，禁止写成狗血争风吃醋。
- 后宫修罗场正面冲突（大奉独有）：修罗场也可写"二选一"的正面冲突——怀庆"我与临安你只能选一个"，临安闯进来"狗奴才你敢背叛本宫"，怀庆"选一个吧"（"长公主剖开来是个黑的"）。写正面修罗场靠"女性角色的腹黑/娇蛮 + 主角夹缝求生"，禁止写成哭闹撕逼。
- 土味情话 + 开车（大奉独有）：主角撩女性用"土味情话 + 隐晦开车"——"殿下就像黑暗中的一道光""倾国倾城的容颜、修长笔直的玉腿、浮夸的36d胸大肌"，女性"又羞又窘又驾驭不住"。写撩妹戏落到"土味 + 开车 + 对方羞窘"，禁止油腻直白的性描写。
- 口嫌体正直（大奉独有）：主角嘴上拒绝、身体诚实——"不去教坊司，老子思考正事""宋廷风你但凡有点良心就别打扰我修行"，骂完拍拍屁股跟着去。写主角日常喜剧用"嘴上不要 + 身体很诚实"的反差，禁止主角一贯正经。
- 倒霉蛋配角喜剧（大奉独有）：用"倒霉蛋"配角制造笑点——钟璃（五师姐）的日常：破刀发狂追杀、法术打散魂魄、被塞糯米糕差点窒息。主角"还好还好""我该拿什么拯救你，我的五师姐"。写配角喜剧可让其"接连倒霉"，主角用吐槽承接，禁止配角纯工具人无笑点。

### 人物成长线
- 主角成长按"品级阶梯 + 身份跃迁"推进：从长乐县快手 → 打更人铜锣 → 银锣 → 卷入朝堂 → 家国战争 → 武神（超品），每次跃迁必须有标志事件（破大案 / 斩杀强敌 / 报恩 / 保家卫国）。
- 成长触发：必须经历失败、绝境或痛失（如魏渊战死）后突破，禁止顺风躺赢突破。
- 从棋子到棋手的成长主题（大奉独有）：主角初期是监正、许平峰、各方博弈的"棋子"，后期必须"成为棋手"（赵守点题："将才易得，帅才罕见，你也不甘心一直被当棋子吧"）。主角的成长主线是"从被摆弄到布局别人"，禁止主角一路只被动挨打、从不主动设局。
- 身负国运的代价（大奉独有）：主角身负国运，命运与朝廷绑定——"大奉若亡，他必殉国"。金手指（国运/气运）必须绑定"国灭身死"的代价，禁止主角只享受国运红利而无任何责任。

## 世界观设定

### 力量体系
- 修炼体系多元并存：武夫（炼精 → 炼气 → 炼神 → ……九品到一品）、儒家、道门、佛门、巫师、术士、蛊师、妖族、神魔；品级从九品到一品，一品之上为超品（神）。
- 各体系之间有明确的能力边界与克制关系，跨体系战斗必须交代"为什么能打/打不过"。
- 品级差距必须通过具体战斗体现，禁止只靠旁白说明"他很厉害"。
- 跨级战斗必须有合理原因（气运加持 / 宝物 / 地利 / 对手状态），禁止低级无解释随意击败高级。
- 儒家"言出法随"（大奉独有）：儒生体系靠"语言就是力量"——低品儒生给目标施加状态（驱寒 / 勇气 / 减轻伤痛），高品大儒一句话即法则（"禁止传送""禁止肢体接触""画地为牢"），且"只要我见过，我就能白嫖"（模仿他人绝学）。写儒家战斗必须落到"言灵 + 白嫖"二字，禁止把儒生写成普通魔法师。
- 佛门"转世重修"（大奉独有）：罗汉想成菩萨（一品）必须转世重修、放弃今生，转世后佛门会寻回前世舍利子植入护道——舍利子是果位、可护主假死涅槃。写佛门必须落"果位 + 转世 + 舍利子"，禁止把和尚写成普通肉盾。
- 道门品级（大奉独有）：道门二品叫"渡劫"、一品叫"陆地神仙"，渡天劫失败灰飞烟灭；地宗道首渡劫失败被魔性反噬成妖道，魔性会"污染"（残暴/贪婪/色欲等邪念滋生，看一眼就堕落）。写道门必须落"渡劫 + 陆地神仙 + 魔性污染"，禁止只写符箓法术。
- 武夫"意"（大奉独有）：四品武夫靠"化劲 + 意"——化劲是人体术巅峰，"意"是武道真意（箭意让箭矢"不射中绝不罢休"、玉碎的绝境之意），四品近身可秒同级。写高阶武夫必须落"化劲 + 意"，禁止只写"力大无穷"。
- 多体系法术实战 + 身份隐藏约束（大奉独有）：战斗中主角常因"不能暴露身份"而禁用招牌绝学（儒家书卷 / 金刚神功 / 天地一刀斩 / 神殊），只能烧魔法书、用隐蔽手段脱身。写战斗必须给主角套"不能用大招"的约束，逼出巧劲，禁止主角无脑甩大招。
- 蛊族七部 + 蛊神之力（大奉独有）：南疆蛊族分七部——力蛊部（饭量极大、食物短缺）、毒蛊部、情蛊部、心蛊部（共情 / 操纵）、暗蛊部、尸骨部（操纵行尸）、天蛊（婆婆）；蛊神之力本质是"蛊神的气血"（黑红萤火虫），力蛊是过滤蛊神毒素的滤器。写蛊族必须落"七部职能 + 气血/蛊虫 + 各怀心思"，禁止把蛊族写成一团模糊的"用蛊的人"。
- 神魔后裔血脉衰弱（大奉独有）：神魔是开天辟地之初天地孕育的，血脉一代代衰弱（即使纯正后裔也一代弱于一代），神魔后裔逐渐演化成"王朝文明"（阿尔苏群岛六部族）。写神魔/后裔必须落"血脉衰弱 + 文明演化"的设定，禁止神魔永远强大不变。

### 世界背景
- 大奉王朝：以武立国、以儒治国，国祚六百年，融合儒、道、佛、妖、术士的架空世界，京城、云州、楚州、北境、南疆等地图逐步展开。
- 势力：大奉朝廷（皇帝 / 监正 / 司天监 / 打更人）、云鹿书院、道门三宗、佛门、万妖国、巫神教、天地会、武林盟等，各有利益诉求。
- 世界观扩展节奏：新设定必须通过主角破案 / 入局 / 遇见新角色时逐步解锁，禁止一次性倾倒设定。

### 规则设定
- 世界核心规则：气运可被实质化（承载国运、影响运气），气运得失有因果代价，这是主角金手指也是全书的规则内核。
- 金手指必须标价（大奉独有）：所有馈赠都暗中标注了价格——主角的气运是被植入的（目的是瞒过监正），收债人（初代监正）会来取；地书碎片身份暴露会"社死"。写金手指必须埋"代价"，禁止主角白拿金手指而无任何后患。
- 气运 = 财运转移（大奉独有）：主角"走路捡钱"其实是"捡走别人的钱"——捡的碎银是李玉春丢的三钱银子，财运是从别人身上转移来的。写气运爽点时必须埋"有人因此倒霉"的代价细节，禁止纯"天上掉馅饼"。
- 洛玉衡"邪火"双修设定（大奉独有）：国师洛玉衡身负"邪火焚身会熔毁道基"的业火，需借气运/精血双修缓解（借元景帝气运压制、借许七安精血炼药引），是后宫线的核心驱动。写女性角色可埋"身体/修为的隐疾"作为与主角结缘的钩子，禁止女性角色无理由倒贴。
- 地书碎片是神识空间（群聊），成员代号交流、身份保密，情报互通但各有算计。
- 当剧情需要突破规则时，必须先铺垫规则漏洞或付出等价代价，禁止临时添加未铺垫的新规则来解围，禁止主角享有无条件规则豁免。

### 经济系统
- 资源获取必须有合理来源（俸禄 / 破案赏赐 / 气运捡漏 / 交易），禁止凭空获得。
- 涉及银两、物价时必须体现换算逻辑（如"十五万两白银重九千三百七十五斤"），禁止数字混乱。

### 社会结构
- 每个势力必须有明确利益诉求（朝廷维稳 / 佛门度化 / 巫神教扩张 / 天地会互助），禁止"为反对而反对"。
- 主角加入或对抗势力必须有合理动机与导火索，禁止无因站队。
- 社会规则（皇权、官场、等级）对主角有真实约束，主角不能无视规则而无后果。

## 对话风格

### 对话比例
- 对话占全文约 26%（引号内对话 4.66 万对），战斗 / 朝堂 / 探案章节对话占比下降，日常 / 勾栏章节可上探。
- 禁止连续超过 3 行纯对话无动作 / 心理穿插；禁止整章无对话。

### 对话风格
- 主角对话：口语化、带现代梗、带推理，风趣犀利；关键时候冒出装逼金句（"淡淡道"）。
- 引导词极简到只剩"道"（全书 29179 次绝对主导），靠前置神态 / 动作 / 声调定性：压场用"沉"、装逼用"淡"、轻松用"笑"、对峙用"冷"、揭底用"缓缓"。
- 古代读书人 / 官场的克制式引导是大奉独有指纹：`沉吟`（539 次，先沉吟再开口，不抢话）、`拱手`（188）、`作揖`（237）、`躬身`（118）等礼仪动作替代情绪直述——这与《灵境行者》的原生都市腔完全不同，禁止让大奉角色用现代无礼方式说话。
- 称谓带官场与市井的等级感：`本官`（425）、`老夫`（117）、`奴家`（106）随身份切换，禁止所有角色用同一种自称。
- 禁止所有角色说话方式雷同；每个主要角色必须有可辨识的说话方式（用词 / 句式 / 语气词 / 说话标记）。

### 对话功能
- 对话必须承担功能之一：推动情节 / 暴露性格 / 传递关键信息 / 制造冲突，禁止无功能寒暄。
- 关键信息通过对话揭露时，必须有说话动机（当事人知情、被套话、显摆、审问），禁止角色无故爆料。
- 禁止角色长篇解说设定（用案件复盘与叙事代替）。

### 对话长度
- 对话短促为主（中位数 11 字），偶发长独白（推理揭底、大儒讲学、喊话）。
- 日常对话不超过 4 轮必须插入动作 / 神态；超过 4 轮的关键对话要分段，中间穿插环境 / 动作 / 心理。
- 禁止一句话超长台词，禁止对话中夹带大段设定解说。

### 口头禅和语气词
- 语气词托底口语感：么（什么/这么/那么/怎么）/ 啊 / 吧 / 吗 / 呢 密集。
- 市井粗口 + 现代梗接地气：干 / 靠 / 操 / 草 / 卧槽 / 逼格 / 社畜 / 韭菜，用于吐槽与日常，禁止用于正式朝堂 / 战场对峙的主角台词。
- 大奉独有：现代脏口大幅退场、古代俚语登场——`娘`（2127，口语里"他娘的"）、`厮`（116，蔑称）、`丫头`（114）、`小娘子`（23）、`狗东西`（45），"逗比/沙雕"等现代脏口几乎绝迹（逗比 1 次），禁止让古代角色骂"卧槽""尼玛"。
- 主角探案口头禅：`不对劲` / `有古怪`，用于发现疑点时。
- 禁止所有角色共用同一口头禅；口头禅每章同一角色不超过 3 次。

## 描写风格

### 环境描写
- 新场景首次登场必须白描环境（牢房 / 县衙 / 勾栏 / 战场 / 朝堂），环境必须服务于氛围（压迫 / 市井 / 肃杀）。
- 单次环境描写不超过 80 字，必须含至少 1 个感官细节（光线 / 声音 / 温度）。
- 市井烟火气靠细节（吃食、银两、节气、器物）而非直述"很热闹"。
- 禁止用环境描写凑字数，禁止环境与当前情绪氛围矛盾。

### 心理描写
- 主角面临谜题 / 重大决策 / 被撩 / 绝境时必须写心理，用内心吐槽 + 行为暗示结合，禁止纯内心独白超 100 字。
- 战斗中不写长心理，只用短句闪念；日常允许深入吐槽。
- 情绪外化优先用极短肢体微反应（皱了皱眉 / 一愣 / 冷笑 / 咧嘴 / 撇嘴）替代心理直述，把情绪压进一个动作。
- 大奉独有：用古代礼仪 / 唾弃类动作外化情绪——`啐`（57，唾弃）、`呸`（122，鄙夷）、`拂袖`（24，怒而离场）、`拱手`（188，施礼）、`作揖`（237）替代现代人的耸肩翻白眼；古代角色禁止出现耸肩、翻白眼这类现代都市化微反应。

### 战斗描写
- 重要战斗（涉及主角 / 关键剧情）必须详细写招式与品级差距；过场战斗一笔带过。
- 每 3~4 个动作必须插入一次拟声词或旁观者反应，禁止纯动作堆砌。
- 胜负必须有逻辑支撑（品级 / 策略 / 宝物 / 状态 / 气运），禁止"因为主角所以赢"。
- 拟声词制造临场感：轰 / 砰 / 啪 / 嗡（战场与武斗密集）。
- 大奉是仙侠武斗而非现代枪战，拟声词以**金铁音为主**：`锵`（75，刀剑相击）、`咻`（68，破风）、`破空`（48）、`铿锵`（33），禁止用枪炮类拟声词。
- 武打用武侠动作词而非现代格斗词：`斩`（1096）、`气机`（611）、`修为`（580）、`剑气`（99）、`丹田`（70）、`心法`（52），招式名与品级挂钩，禁止"一拳一脚"式的现代格斗描写。

### 情感描写
- 用行为和细节暗示情感，禁止直接写"他很伤心 / 她很感动"。
- 情感爆发（牺牲、离别、意难平）前必须有压抑铺垫，禁止突然煽情。
- 男女情感落"风流 + 留白"，禁直白告白式煽情；家国情感要落到"为苍生 / 万世开太平"的立意上。
- 遗物式情感（大奉独有）：写离别/死亡不写嚎哭，写遗物——浮香死后留下两封信、一本书、一只玉镯，信里倒出一片干巴发皱的莲瓣，主角"忽然有种窒息般的感觉"（"原来从始至终，我给你的，仅仅只有这些而已"）。用一件具体小物承载全部情感，禁止直写"他很悲痛"。
- 现代意象写悲伤（大奉独有）：全书少见的抒情时刻用现代生活意象而非古诗文——"真正深切的悲伤不是爆发性的大哭一场，而是打开冰箱的那半盒牛奶、那窗台上随风微曳的绿箩、那折叠在床上的绒被"。写深悲可借穿越者的现代记忆意象，禁止堆砌"泪如雨下"。
- 底层温情 + 无辜者死亡的愤怒（大奉独有）：主角对底层有真实的善——给贫苦母女碎银、小姑娘回赠地瓜干、主角"目光一下柔软起来"；而面对无辜者被灭口（母女被灭口、母亲抱紧女儿），主角"额头的青筋跳了起来"。写主角的善与愤怒落"具体的小人物 + 具体的愤怒反应"，禁止主角空喊"我很愤怒"或对底层无感。

### 感官描写
- 视觉 + 听觉为基本（拟声词密集），战斗 / 战场必须加入触觉 / 痛觉 / 冷热。
- 嗅觉、味觉明显弱化，可选择性补足（勾栏 / 市井戏可加香 / 苦 / 鲜）但非必要。
- 禁止仅用视觉描写，禁止感官与场景不匹配。

## 题材专项能力

### 探案流设计
- 每个案件必须有一个"科学破绽"或"逻辑漏洞"：主角用现代知识（质量换算 / 化学 / 痕迹学 / 心理学）或纯逻辑（时间对不上 / 物证矛盾）拆穿表面结论。
- 案件结构三步走：① 抛出现场最明显的误导线索（妖风 / 爆炸）；② 主角做减法、逐条排除；③ 用一条被忽略的细节翻盘。
- 关键：主角破案必须把推理过程**摊开给读者看**（"推理最重要的是做减法"），让读者同步推理，禁止主角藏着答案到结尾才揭。
- 案件必须"串案"：一个小案牵扯出背后的大局，禁止孤立的单元案。
- 破案靠"心理操控 + 专业细节"双管齐下（大奉独有）：① 话术套供——编故事（"欲说还休"）诱导对方发言，再故意曲解对方的话扣帽子（"大师说大奉是苦海，桑泊案是皇室的报应"→"抓人啊"钓鱼执法）；② 微表情观察——"仔细观察他们的微表情和细微动作"；③ 行业冷知识——"矿石磨得太细=贪腐冲量""衙门门口不可能闹水匪"；④ 专业手语团队协作——隐蔽打手势下令"准备行动"。禁止主角破案只靠"灵光一现"或纯武力。
- 验尸法医细节（大奉独有）：破案靠"尸体不会说谎"——通过"左手中指有茧=左撇子""创口左深右浅=右手持刀"判断"他杀而非自杀"，用"颈动脉割断会挣扎"否定"畏罪自杀"的坐姿。写法医戏必须落到具体可查的身体细节，禁止"他一看就知道是自杀"。
- 行为心理学破案（大奉独有）：通过"行为模式反推动机"——妖物"只吃进山的灰户、不吃村庄"=有意识的驱赶=划地盘=山里有它在乎的东西。写推理戏可以跳出现场证据，从"对方行为的反常"推出深层动机，禁止只会物证堆砌。
- 现代化学实验破案（大奉独有）：用化学实验现场辨物——"白色矿石捏碎撒火→火焰明黄带紫"判断是"硝石"（焰色反应）。写科学破案可落到具体的化学/物理小实验，禁止空喊"我懂科学"。

### 抄诗流设计
- 抄诗装逼必须**借他人之口吟出**或主角在关键场合抛出，诗必须是真实后世的传世名篇，禁止生造伪诗。
- 爽点落在旁观者的震惊、嫉妒、争抢反应上（大儒抢收徒 / 学子传唱），禁止主角自夸。
- 抄诗要"留一手"（如"只有半阙"），制造悬念与余味，禁止一次抖完。

### 气运金手指设计
- 气运是实质化的：运气好表现为"走路捡钱 / 化险为夷"，但必须搭配主角的脑子，禁止纯运气无脑过局。
- 气运有来源（身负国运 / 道尊遗留国运）与代价（因果纠缠 / 被人觊觎），禁止无限开挂。
- 地书碎片（神识群聊）是情报网：成员代号交流、身份保密、各怀算计，禁止群聊变万能工具。

### 灵异恐怖元素（大奉独有，探案 + 仙侠 + 灵异三合一）
- 恐怖感靠"感知错位"而非血腥直述：怪物"无声无息、只闻呼吸腥臭、火光骤亮才看清"，魅（艳鬼）"化作纸人替身、尖锐笑声"，古墓"鬼打墙"（三次走回同一偏室）。
- 恐怖桥段必须服务于探案或成长（镇墓兽护墓、魅背后有主人、封印物逃脱），禁止为恐怖而恐怖。
- 惊悚落点：主角的生理反应（头皮发麻、脊背生寒意）+ 短句加速，禁止用"好恐怖"直述。

### 家国权谋升维（大奉主线，从探案升维到天下）
- 主线结构：破小案 → 牵扯出朝廷阴谋 → 卷入家国战争（血屠三千里 / 巫神教入侵 / 镇北王屠城）→ 守护大奉。探案是表，权谋是骨。
- 权谋博弈靠"信息差 + 多方算计"（魏渊布局、监正下棋、镇北王屠城、巫神教扩张），各方动机必须有利益驱动。
- 主角在家国大义前必须有坚守（为苍生、为冤死忠臣正名），禁止主角只求自保、格局拉不满。

### 马甲错位 + 网络人设反差（大奉独有，地书碎片的喜剧核）
- 地书碎片（神识群聊）让主角有了"网络人设"：现实里羞耻、网上"睿智重拳出击"，用云淡风轻的姿态化解尴尬。
- 马甲错位制造喜剧：主角冒充堂弟许新年当"三号"，被识破后"反向社死"——所有人都知道但都不说，反而自己没社死、替隐瞒的人社死。
- 写群聊戏必须"网络与现实反差"：网上用代号装逼，现实里脚趾抠地，禁止群聊与现实一个语气。

### 古墓壁画叙事 + 考古推理（大奉独有，探案 × 考古融合）
- 用壁画/器物承载世界观信息 + 推动推理：墓室壁画讲一个"道人斩蛇→篡位称帝→沉迷双修→天劫劈死"的故事，主角团队"看壁画→推理→联想到元景帝"。
- 壁画内容必须"看起来是神话、实则是历史暗喻"，让主角边看边推，禁止旁白直接倾倒设定。
- 考古推理的钩子：壁画/器物里藏着与主线呼应的线索（篡位道人=元景帝的影射），让读者与主角同步"细思极恐"。

### 寓言式隐晦伏笔（大奉独有）
- 关键线索藏在"看似无关的随笔/故事"里：浮香留下的书里写"鹰的孩子被欺负→狐狸诱骗→老虎包庇→猴王查案→蟒蛇诬陷大黑熊→黑熊杀狐狸"，是一则影射朝堂阴谋的动物寓言，主角"有浓浓的既视感，但一时想不起来"。
- 写隐晦伏笔可用"寓言/童谣/梦境"包装，让线索半明半暗，禁止伏笔过于直白一眼看穿。

### 黑暗真相 + 主角底线（大奉独有）
- 主线大案的真相是"黑暗"的：龙脉地底"尸骨如山"，四十年被拐百姓被屠杀在龙脉之上（血屠三千里 / 屠城炼气运）。真相揭露时主角必须有强烈的情绪反应（"畜生！"牙缝里蹦出）与底线坚守。
- 写黑暗真相必须"先铺垫大量诡异（楚州恢复原样、无缘无故的失踪），再揭底尸骨如山"，让读者与主角一起毛骨悚然，禁止毫无铺垫突然甩一个黑暗真相。
- 主角面对大是大非必须有底线（为冤死忠臣正名、斩权贵、保家卫国），禁止主角面对黑暗无动于衷或只想自保。

### "一人三者"惊天反转 + 共同推理（大奉独有，全书最大反转）
- 全书最大的反转是"身份同源"：主角一直查"元景帝被地宗道首污染"，真相是"先帝一气化三清，先帝/元景/淮王父子三人是同一个人"。反转必须靠前期埋的"不合理细节"（元景对淮王过度的信任、魂丹功效、平远伯原地踏步二十年）在揭底时全部串起，禁止毫无铺垫的惊天反转。
- 推理不是主角独享，而是主角与配角**共同推演、互相纠正**：怀庆（一号）点出主角"陷入思维误区"（二品道士驾驭不住一气化三清？），主角才推翻自己的判断。写推理反转必须让聪明配角质疑主角、主角重新审视，禁止主角永远正确、旁人只负责震惊。
- 用画像辨认身份（大奉独有）：画出嫌疑人画像给目击者辨认（"是他吗？""不是他"→换第二张→"就是此人"），层层排除确认身份。写身份确认可落到"画像辨认"的具体动作，禁止主角凭直觉断定。

### 套路运用
- 打脸权贵：3 步完成——被轻视（身份低）→ 展现实力（破案 / 诗词）→ 对方震惊，禁止拖沓。
- 抄诗装逼：间隔至少 10 章一次，且每次换不同诗、不同场合，禁止连续抄诗。
- 身世反转：全书仅用 1~2 次，必须前期埋可查证的蛛丝马迹。
- 套路创新：同一套路不可连续使用，必须换变体。
