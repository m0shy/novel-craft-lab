## 四、语言指纹（写作时直接执行）

1. **句式节奏**：短句定节奏、长句做说明，句长中位数 31-34 字、CV 0.77。紧张场景用短句/断句/拟声词加速（"数台阶，一级，两级，三级……十二级。爬到八楼。"）；日常/吐槽/推理允许中长句铺陈。禁止碎句连排。
2. **段落节奏**：平均 26-30 字，一句话一段是主形态；偶发长段只做科学说明或背景科普。禁止大段堆砌。
3. **标点指纹**：省略句 16.7%，"……"做停顿/留白/悬念；感叹号克制（4.6%）。
4. **词汇光谱**：科学硬核 + 军事动手 + 暴力美学三高叠加，语气词/粗口/判断词三层托底。脏口克制（卧槽全书仅 23 次）。
5. **对话系统**：对话占比 1/5-1/4，中位数 9 字短促；"道"打底 + "副词/神态 + 说道"定性；禁止纯对话流超过 3-4 轮无动作穿插。
6. **元叙述吐槽**：角色/旁白直接吐槽情节（全书直接写"吐槽"219 次），用于松节奏、破紧张、立人设，点到即止。
7. **微反应外化**：挑眉/眉头微皱/一挑眉梢/眼角一抽/撇嘴/咧嘴/一愣，情绪压进动作，禁止"他很伤心"式直述。
8. **拟声词临场感**：轰/砰/咔/啪/咚/咔嚓/呲，每 3-4 个战斗动作插入一次。
9. **五感配比**：视觉 + 听觉主导，触觉（冷/麻/痛）强于一般爽文，嗅觉味觉弱化。
10. **推理口头禅**：可能（2360）/ 那么 / 也就是说 / 就是，用于展开推理链时。

## 五、叙事模型体系（七大模型定版）

> 合并 create-author v4 规则、fiction-polish-distill 六大模型、wenfeng 五模型的去重结果。

### 模型 1：怪谈开局 + 冷静推理去魅

用一条都市怪谈或离奇凶案开场，主角以冷知识加逻辑推理一步步还原真相，把恐怖事件"去魅"成可解释的机制。开篇一章内立住：① 核心能力（超强推理 + 动手能力 MAX）；② 核心矛盾（真实游戏入侵现实）；③ 独特人设（野生天才 + 伪精神病 + 满嘴骚话）。推理线必须真有逻辑闭环，不能"灵机一动"；恐怖氛围铺够之后必须给出合理解释。

### 模型 2：杀场副本游戏化制

把叙事装进"地球杀场"游戏外壳：系统提示【】、任务目标、时间限制、奖励、失败惩罚、强制传送。副本结构三步走：① 系统发布任务；② 主角观察、列可能性、逐一排除；③ 用一条被忽略的细节翻盘。核心规则：玩家资格可转移（击杀玩家获得资格）、完全扮演模式禁金手指、杀场游戏本质是"战争"（文明-星球-位面-晶壁系-多元宇宙的战争磨盘）。系统提示是调味不是主体，面板内容必须克制（任务目标/时间限制/奖励惩罚），禁止面板盖过叙事。

### 模型 3：马甲 / 身份错位（含战略切割）

主角靠多重马甲在副本里周旋：西门子道人（招摇钓鱼）、书生扮相（低调潜伏）、危月燕（武力掩护）、毕加索脸（幻术改五官）。马甲要"招摇 vs 低调"反差；高级形态是**身份切割**——李昂用"李日升"马甲把自己伪装成第二梯队召唤玩家，与虫巢划清界限。每个马甲必须回答"它在掩护什么"，禁止只换名字无实质作用。幻术是技术支撑，有明确弱点（远距离逼真、接近即穿帮）。

### 模型 4：冷知识 / 专业术语外化降维

主角把推理过程和冷知识显性输出，让"知识即武器"。开篇"鲸落理论"破案、视杆细胞 4:1 vs 猫 25:1 解释夜视、解剖学名词精确打击（寰椎、额骨、蝶骨）、撬锁写到锁芯销子。知识必须真实可查、通俗可懂，禁止堆术语炫技。

### 模型 5：恐怖 × 喜剧快速交替

恐怖氛围压到顶点时用一句反差梗破局（恐怖场景配萌梗、残尸配食物："没啃干净的泡椒凤爪"）。恐怖分两类，解法不同：**无解灵异**（"怪异"，无法沟通，如《咒怨》）只能靠推理与苟活；**可沟通恶灵**（有人类记忆情绪）可以谈判合作。极致恐怖靠"剥夺"（色彩剥夺式氛围）与"身体错乱"（body horror），不靠堆血浆。关键高潮的严肃性不能被喜剧消解。

### 模型 6：元叙述吐槽（打破第四面墙）

角色或旁白直接吐槽叙事本身，是《玩家凶猛》区别于卖报小郎君的最大对话特色。用于松节奏、破紧张、立人设。中二配音破冰是其延伸形态（多人对峙时用苍劲雄浑声线配音"十四位至尊，一念花开，君临天下"）。点到即止，不能频繁到破坏沉浸。

### 模型 7：虫群战略战争（后期体系）

虫群是"战略系统"而非召唤物：虫巢基地（雷达/脑虫/基因资源库/消化池/灵能塔/孵化池流水线）+ 兵种分级（侍从/野兽/重装/卫队/脑虫）+ 以战养战（菌毯回收尸体、消化池吸收生物质）。武器生物化（食肉甲虫步枪、蚤虫机炮、爆裂炮），信仰之力做神格资源（门扉世界信徒祷告跨星门补灵，收支平衡）。**宏观战争必须有微观锚点**——巨人免疫系统战争落在溶酶体酶腐蚀、微绒毛切割、透过半透明细胞膜看见溶解的兵虫，禁止"百万大军对冲"空镜头。

## 六、笔法规则体系（写作能力定版）

> 以下为 v4 最终版（文风skill_7）全规则精要，按模块归类。完整规则存于 skill_7 的 writing.md / SKILL.md（未随仓库发布）。

### 6.1 叙事

- **视角**：第三人称限知，POV（叙事视角人物）锁主角李昂，允许短暂借旁白交代其他角色外部动作神态（第一章直接进王警官视角），禁止深入配角内心独白。
- **节奏**：每章至少 2 个事件推进点；对话不超过 3 轮必须插入动作/神态/心理；恐怖危机场景短句加速；章末必留钩子（反转/新线索/反常的话/"不对劲"的发现）。
- **手法**：副本串式结构滚雪球（一个副本牵扯出更大的局），禁止孤立单元副本；长线伏笔（杀场游戏本质、前五次生物大灭绝、巨人/世界树、主角身世）可跨数百章但必须前期留可查证线索；信息碎片化释放。
- **时间线**：主线线性，时间用季节/气候/校园作息标记；系统面板打断时内容克制；回忆用吐槽插入限 1-2 句，禁止大段闪回。

### 6.2 情节

- **开篇**：怪谈开局（张翠莲死亡案）+ 鲸落推理 + 反杀获玩家资格，一章完成"普通人→玩家"跃迁；开篇禁止大段世界观设定。
- **高潮**：主角陷绝境（完全扮演模式/被碾压）→ 靠临场推理/反套路/预留后手翻盘，禁止机械降神；高潮前必须有可回头查证的铺垫；反派智商不得下线。
- **收尾**：章末必含钩子或反转；副本收尾必须"揭底"（疑点→假设→验证→结论摊开）；全书收束要交代主线谜底，禁止留一堆未填伏笔（原书结尾仓促是已知短板，仿写时应主动修正）。
- **推进**：事件驱动 + 推理驱动双轮；禁止纯巧合、反派送人头、配角长篇解说替主角解密；每 3-5 章一次实质推进。
- **爽点**：副本智斗 / 一本正经胡说八道（严谨与荒谬反差）/ 反套路（读者意外感）/ 民俗仪式反套路搅局（庄严仪式被解构）/ 扮猪吃虎（当章或下一章内反击）。连续 3 章无爽点，下一章必须安排一个。

### 6.3 人物

- **主角李昂**：17 岁高中生，孤儿院长大（七岁失怙失恃），半工半读，野生天才 + 伪精神病 + 动手能力 MAX（撬锁/爆破/野外生存/手搓核弹）。金手指四件套（科学推理 + 幻术眼珠 + 生物母版 + 虫群控制/沼泽神力），使用限制明确（前期无属性强化、完全扮演模式禁物品栏、异能消耗精神力）。禁止：无理由圣母心、对敌废话连篇、明知陷阱还跳、为女人不顾大局。
- **配角**：一人一功能 + 一人一说话标记（王丛珊"翻白眼/彪子"、万里封刀"蛋疼吐槽"、邢河愁"李兄弟"、柳无怠"寡言"、柴翠翘"傲娇吃货"）；原书配角塑造偏单薄（读者公认短板），仿写时主动加强配角的独立动机与成长线。
- **反派**：威胁来源明确、动机有利益驱动、前期占优势，禁止"纯粹的恶"与降智送死。
- **关系**：新角色 3 章内建立明确关系；男女关系靠"斗智斗勇 + 生死互助"升温（夏洛克与华生式），禁止无铺垫动心；主角道德感薄弱，需"人性锚点"（王丛珊）贯穿拉住。
- **成长**：Lv1 新手 → 副本玩家 → 超凡者 → 特事局对抗者 → 半神 → 造物主，每次跃迁有标志事件，必须经历绝境/失败/痛失后突破，有"自己肝出来"的实感。

### 6.4 世界观

- **力量体系**：玩家等级（Lv）→ 技能 → 异能 → 神格/造物主；装备品质分级（普通→稀有→神话），特效必须交代生效条件与代价；跨级战斗必须有合理原因。
- **世界背景**：地球杀场（一切幻想作品都是其他世界的投影）；前五次生物大灭绝 = 前五次杀场游戏失败（第七次轮到人类）；势力全球分布（特事局/异学会/岿阳派/蜃龙/门扉世界/星界/虫群/天使军团 + 全球超自然联盟/FBI 特异事故处/德意志异常事务调查局/守望者结社）；**国际势力博弈**（特事局 vs 中情局/德意志/MI6/普罗米修斯实验室，大英博物馆文物藏超凡物品）；公会六分类；竞技体系（天空斗技场→五百强→境域回廊→门扉争夺战）。
- **规则**：突破规则必须先铺垫漏洞或付出等价代价，禁止临时添加未铺垫的新规则解围。
- **经济**：资源获取必须有合理来源（副本奖励/游戏币/交易/猎杀掉落），游戏币经验值体现换算逻辑。
- **社会**：每个势力有明确利益诉求；现实规则对主角有真实约束（毁尸灭迹、装环卫工清理现场），不能无视规则而无后果。

### 6.5 对话

- **风格**：口语化 + 现代梗 + 科学推理 + 满嘴骚话；引导词"道"打底 + 副词说道定性；古风副本硬塞现代梗制造认知错位笑点（"这个时代貌似还没有墨镜吧？"）；禁止所有角色说话方式雷同。
- **功能**：必须承担五功能之一（推动情节/暴露性格/传递关键信息/制造冲突/制造笑点）；关键信息揭露必须有说话动机；禁止长篇解说设定。
- **口头禅**：语气词托底（么/吧/啊/呢/吗）；东北腔接地气（整 2210 最高频/干/靠/浪/蛋疼/我去/老铁/整活）；文雅自黑；推理口头禅（可能/那么/也就是说）；同一角色口头禅每章不超过 3 次。

### 6.6 描写

- **环境**：新场景首次登场必白描，单次不超过 80 字，必含至少 1 个感官细节；恐怖靠细节（尸斑、人面猫、干涸血迹、腐烂气味）而非直述；色彩剥夺式氛围做极致恐怖。
- **心理**：谜题/重大决策/绝境必写心理，内心吐槽 + 行为暗示结合，禁止纯内心独白超 100 字；战斗只用短句闪念。
- **战斗**：重要战斗详写招式与等级差距，过场一笔带过；每 3-4 个动作插入拟声词或旁观者反应；胜负必须有逻辑支撑；拳拳到骨的暴力美学，禁止光波对轰；宏观战争用微观锚点落地；游戏外挂可以战斗化（超级瞄准/十米金身/红太狼挂）；身体恐怖克制使用。
- **情感**：用行为和细节暗示，禁止直述；情感爆发前必须有压抑铺垫；男女情感落"斗嘴 + 留白"（男方整活、女方吐槽，感情藏在"整活与吐槽"的往返里）。

### 6.7 更新习惯

- 模拟稳定日更节奏（原书两年零三个月 299.93 万字，日均约 4000 字）。
- 每章 2000-3000 字（原书均值 2247、中位数 1903），单次输出按一章交付。
- 模拟晚间更新，章末留钩子。
- 断更需说明理由并预告补更（原书因起点整顿灵异类转向求生是正面范例）。
- 重大节点可爆更，日常不承诺爆更。

### 6.8 题材专项能力（v2-v4 新增规则汇总）

- **副本解谜流**：每个副本必须有规则/谜题；三步走（发布任务→列可能性排除→被忽略的细节翻盘）；推理摊开给读者同步推；副本必须"串本"。
- **民俗灵异副本**（红白双煞/百鬼夜行/借阳寿成亲）：民俗禁忌做恐怖底子，科学祛魅 + 沙雕搅局破解，禁止纯吓人不解谜、纯搞笑不吓人。
- **多人副本猜疑博弈**：玩家互相提防再被迫合作，沙雕骚话承担破冰功能，禁止一条心打怪。
- **鬼魂合作流**（孤寒寺模式）：恶灵给完整悲剧背景（柴翠翘）+ 双向算计（情况一/二/三逐条权衡）+ 反制手段（猫眼幻术暗中定住）+ 悲剧白描克制（被砍成几截、埋在后山），禁止无脑信鬼、禁止把命门交给鬼。
- **科学降维**：科学方法用到荒谬处（摸牙齿、测身高、干呕看内容物判断身体归属）；解释通俗可懂；与怪谈碰撞时逻辑自洽。
- **系统面板**：面板克制（任务目标/时间限制/奖励惩罚），面板刷屏配主角反应（"这么灵？"），完全扮演模式封金手指逼智斗。
- **虫群战略 + 生物武器化 + 信仰之力收支 + 游戏外挂战斗化 + 马甲身份切割**：见模型 7 与模型 3。

## 七、风格 DNA 九条 + 禁止项清单（定版）

### 风格 DNA 九条（可执行规则）

1. **短句定节奏，长句做说明**：句长中位数 31-34 字，CV 0.77，允许比一般爽文更长，禁止碎句连排。
2. **科学硬核解构**：写超凡先给科学解释，战斗精确到解剖学/机械名词，知识既是推理工具也是暴力手段。
3. **暴力美学落实处**：血/断/裂/碎/爆/骨 + 解剖学名词 + 拟声词，拳拳到肉，禁止光波对轰。
4. **沙雕玩梗反差**：恐怖顶点用童年动画梗/食物比喻/网络梗破局，梗与推理一体。
5. **系统任务驱动**：【】冷硬发布，格式结构化（任务名/目标/时限/奖励），奖励与难度正相关。
6. **副词 + 说道**：引导词"道"打底，靠"随口说道/平静地说道/微笑着说道"定性，禁止堆"说"字形容词。
7. **微反应替代心理描写**：一愣/一顿/咧嘴/挑眉/瞳孔/咽口水，情绪压进动作。
8. **元叙述吐槽**：角色/旁白直接吐槽情节，主角"活跃气氛"破紧张，点到即止。
9. **省略号制造余味**：省略句 16.7%，话说到一半"……"留白，恐怖用"……"收尾。

### 禁止项清单（违禁即不合格）

- 禁止碎句连排的短剧腔（平均句长 31-34 字是硬指标）。
- 禁止"说"字堆形容词（不写"激动地说/悲伤地说"），一律"道/说道" + 前置神态。
- 禁止主角推理藏在幕后或由旁白代答，推理必须外化、可被读者跟推。
- 禁止光波对轰式抽象打斗，战斗必须有肉体/器械层面的真实碰撞。
- 禁止系统规则"作者说了算"式降神，规则必须自洽、可被推导。
- 禁止堆书面化套话与 AI 式逻辑连接词（"一方面……另一方面……"论文腔）。
- 禁止凭空降神破局，主角的"歪招"必须建立在可验证的科学/逻辑依据上。
- 禁止文艺腔抒情、煽情形容词堆砌、四字成语滥用、空洞三段式排比。
- 禁止在关键高潮处用玩梗消解严肃性。
- 禁止圣母式主角，主角应是腹黑、行动派、有真实欲望的。
- 禁止无解灵异与可沟通恶灵混为一谈（两类副本解法不同）。
- 禁止把虫群写成"喊一声就出来的小怪"（战略系统有完整运营逻辑）。
- 禁止马甲只换名字无实质作用（每个马甲必须回答"它在掩护什么"）。
- 禁止直白告白式煽情（感情藏在"整活与吐槽"的往返里）。
- 禁止主角满嘴纯脏口（卧槽全书仅 23 次，文雅自黑才是原味）。
- 仿写禁用破折号（个人铁律优先于原文统计；原文确大量使用"——"，仿写时用逗号/句号/省略号替代）。
