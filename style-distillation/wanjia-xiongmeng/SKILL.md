## 叙事风格

### 叙事视角
- 第三人称限知视角，POV 锁定主角李昂，但允许短暂"借旁白"交代其他角色的外部动作与神态（第一章直接进入王警官视角），禁止深入其他角色的内心独白。
- 主角的推理、吐槽、腹诽必须以内心独白 + 自言自语外化（`嘀咕` / `心里` / `念头`），禁止旁白代答主角在想什么。
- 主角的"高智商"必须外化为可见的推理过程（观察 → 列可能性 → 排除 → 结论），禁止旁白一句"他很聪明"带过。
- 其他角色只通过动作、神态、台词被"看见"；若必须交代其心理，只能借主角的观察与推断转述。

### 叙事节奏
- 每一章必须包含至少 2 个事件推进点（线索发现 / 危机升级 / 谜题破解 / 关系变化），禁止连续 3 段纯描写或纯设定而无事件。
- 对话段落不超过 3 轮就必须插入动作、神态或心理，禁止无间断对话流。
- 恐怖/危机场景用短句、断句、拟声词加速（"数台阶，一级，两级，三级……"）；日常/吐槽场景允许中长句铺陈。
- 每章结尾必须留钩子（一个反转 / 一条新线索 / 一句反常的话 / 一个"不对劲"的发现），禁止以平静收束结尾。

### 叙事手法
- 主线顺叙推进，用"一个副本 → 牵扯出更大的局 → 再破一副本 → 又牵出更大的局"的**副本串式结构**滚雪球，禁止孤立单元副本。
- 长线伏笔（杀场游戏本质、前五次生物大灭绝、巨人/世界树、主角身世）可以跨数百章，但必须前期留可查证线索，禁止凭空降神。
- 悬念信息碎片化释放：靠副本、系统提示、他人对话片段层层剥洋葱，主角实时推理并纠正自己的判断。
- **马甲 / 身份错位是招牌手法**：主角靠多重马甲在副本里"大隐隐于市"——西门子道人（招摇的江湖道士）、书生扮相（吕州城掩饰身份）、危月燕（柴翠翘的青铜重甲马甲）、毕加索脸（幻术改五官）。每个马甲要有明确用途（招摇钓鱼 / 低调潜伏 / 武力掩护），且马甲的"招摇"与"低调"之间要有反差（招摇的西门子 vs 低调的书生），禁止马甲只是换个名字无实质作用。

### 时间线处理
- 主线线性推进，时间流逝用季节、气候、校园作息等细节标记（"夏末，夜色渐晚""周一，上午七点五十分"）。
- 系统面板【】打断叙事时，面板内容必须克制（任务目标/时间限制/奖励惩罚），禁止用面板长篇倾倒设定。
- 主角对孤儿院、童年的回忆用吐槽插入，限制在 1~2 句内，禁止大段闪回。

## 情节构建

### 开篇套路
- 第一章必须"怪谈开局"：用一起离奇命案（张翠莲死亡案）勾住读者，主角靠"鲸落理论"推理 + 反杀（击杀玩家获得玩家资格）完成从"普通人"到"玩家"的跃迁。
- 开篇禁止大段世界观设定；杀场游戏、副本、势力分布等信息必须随主角入局逐步解锁。
- 开篇必须建立的读者认知：① 主角的核心能力（超强推理 + 动手能力 MAX）；② 核心矛盾（真实游戏入侵现实）；③ 主角的独特人设（野生天才 + 伪精神病 + 满嘴骚话）。

### 高潮设计
- 高潮必须满足：① 主角陷入绝境（完全扮演模式无金手指 / 被强敌碾压）；② 靠"临场推理 / 反套路 / 预留后手"翻盘，禁止机械降神。
- 高潮前必须有铺垫（早埋的线索、已建立的人脉、前文提过的知识），铺垫内容必须可回头查证。
- 反派/怪物败因必须合理：主角以更硬核的推理或更反套路的操作反杀，禁止反派智商下线。

### 收尾习惯
- 每章最后一段必须含钩子或反转，禁止"欲知后事如何"式套话。
- 副本收尾必须"揭底"：主角把"疑点 → 假设 → 验证 → 结论"一条条摊开，让读者同步推理，禁止藏着答案到结尾才揭。
- 全书收束可"格局拉满"（主角成神 + 无限战争拉开序幕），但必须交代主线谜底（杀场游戏的本质），禁止留一堆未填的伏笔就谢幕（原书结尾仓促是已知短板，仿写时应主动修正）。

### 情节推进方式
- 事件驱动 + 推理驱动双轮，推理必须外化给读者，禁止幕后解谜。
- 禁止靠纯巧合推进；禁止反派主动送人头；禁止配角长篇解说替主角解密。
- 每 3~5 章必须有一次性推进：副本突破 / 实力升级 / 关系变化 / 势力归属 / 身份揭示其一。

### 爽点设计
- **副本智斗**：主角用高智商 + 反套路操作碾压副本 BOSS，破解瞬间必须有"原来如此"的爽感托底。
- **一本正经胡说八道**：用科学知识（鲸落理论 / 视锥细胞 / 概率 / 基因）一本正经地解释荒谬怪谈，爽点落在"严谨与荒谬的反差"上。
- **反套路**：主角不按常理出牌（自我介绍是"红领巾"、迟到理由是"被麻婆豆腐追杀十八条街"、安慰同学用蛆虫），爽点落在读者的意外感。
- **民俗仪式反套路搅局**：把严肃的民俗仪式（借阳寿成亲、红白双煞）用沙雕手段搅成闹剧——幻术控制司仪用口音普通话乱念婚礼词（"新囊，是个好鹅囊""同肛共苦，天残地久"），爽点落在"庄严仪式被解构"的反差上。
- **扮猪吃虎**：被轻视（普通高中生身份）后必须当章或下一章内反击，反击靠智商或动手能力，禁止纯靠运气。
- 爽点间隔：连续 3 章无爽点时，下一章必须安排一个（吐槽 / 反套路 / 智斗 / 扮猪吃虎其一）。

## 人物塑造

### 主角设定
- 主角李昂：17 岁高中生，孤儿院长大（七岁失怙失恃），半工半读，野生天才 + 伪精神病 + 动手能力 MAX（撬锁 / 爆破 / 野外生存 / 手搓核弹），脑回路清奇但关键时刻智商碾压。
- 遇到谜题 / 危机时必须先"一本正经"地科学推理 + 吐槽，禁止面对谜题直接"灵光一现"。
- 主角的骚话必须有"玩梗 + 逻辑自洽"的双重性（"犹豫，就会败北"既能玩梗又能推进），禁止无意义嘴炮。
- 主角禁止出现：无理由圣母心、面对敌人废话连篇、明知陷阱还往里跳、为女人不顾大局。
- 金手指：① 超强科学推理 + 动手能力；② 幻术眼珠（识别/制造幻象）；③ 生物母版（改造身体）；④ 虫群控制 + 沼泽神力（后期成神）。使用限制：前期无属性强化、完全扮演模式禁物品栏、异能消耗精神力，禁止无限开挂。

### 配角塑造
- 每个有名配角必须有"说话标记"或独特行为习惯（王丛珊的"翻白眼/彪子"、柴柴的"吃货/圣女"、石青松班主任的"气乐了"），一开口就能辨人。
- 队友群像必须"一人一功能 + 一人一说话标记"：万里封刀（吐槽担当，口头禅"翻白眼/蛋疼"）、邢河愁（稳重担当，敬称"李兄弟"）、柳无怠（淡然强手，寡言少语）、柴翠翘（傲娇吃货），禁止所有队友一个模子。
- 配角至少承担一个功能（推动情节 / 提供信息 / 制造冲突 / 情感张力 / 提供笑点），禁止纯工具人。
- 女性群像用"类型 + 反差"立人设（青梅竹马王丛珊的人性锚点、柴翠翘/柴柴的吃货反差、素霓笙、米迦勒各具一格），禁止所有女性一个模子。
- 原书配角塑造偏单薄（读者公认短板），仿写时应主动加强配角的独立动机与成长线。

### 反派设计
- 反派/怪物必须有明确威胁来源（怨念 / 副本规则 / 更高层玩家 / 神明），动机有逻辑链条。
- 反派动机必须有明确利益驱动（吞噬 / 抢夺资源 / 维护游戏规则 / 追求超脱），禁止"纯粹的恶"。
- 反派必须在主角成长前占据优势，主角翻盘靠自身推理、反套路或预留后手，禁止反派降智送死。

### 人物关系构建
- 新角色登场后 3 章内必须与主角建立明确关系（敌 / 友 / 中立 / 暧昧）。
- 关系变化必须有事件驱动；男女关系靠"斗智斗勇 + 生死互助"升温（李昂与王丛珊的"夏洛克与华生"式互动），禁止无铺垫的突然动心。
- 主角因童年被拐/孤儿院经历道德感薄弱，需要"人性锚点"（王丛珊）拉住，这条线必须贯穿，禁止主角彻底黑化或突然圣母。

### 人物成长线
- 主角成长按"玩家等级 + 身份跃迁"推进：从 Lv1 新手 → 副本玩家 → 超凡者 → 特事局对抗者 → 半神 → 造物主（成神），每次跃迁必须有标志事件。
- 成长触发：必须经历绝境、失败或痛失后突破，禁止顺风躺赢突破。
- 成长要有"自己肝出来"的实感（拳拳到肉的战斗、亲自动手的改造），禁止纯面板数值跳升。

## 世界观设定

### 力量体系
- 力量体系：玩家等级（Lv）→ 技能 → 异能（心灵创造系 / 沼泽神力等）→ 神格 / 造物主，品级清晰有边界。
- 装备道具按品质分级（普通 → 稀有 → 神话），道具特效必须交代生效条件与代价（幻术眼珠需精神力、需眼眶结构）。
- 跨级战斗必须有合理原因（反套路 / 道具 / 地利 / 对手状态），禁止低级无解释随意击败高级。
- **虫群是"战略系统"而非召唤物**：虫巢基地（雷达/脑虫/基因资源库/消化池/灵能塔/孵化池流水线）+ 兵种分级（侍从级/野兽级/重装级/卫队级/脑虫）+ 以战养战（菌毯回收尸体、消化池吸收生物质），虫群有迁移、生产、情报、扩张的完整运营逻辑，禁止把虫群写成"喊一声就出来的小怪"。
- **生物武器化**：武器都是活体——食肉甲虫步枪（虫卵当子弹，命中体内孵化幼虫）、蚤虫机炮（跳蚤弹射）、热熔炮、爆裂炮（蜱虫炮弹）——克苏鲁式"生物当军备"，设计武器时必须交代生物原理。
- **信仰之力是后期神格资源**：门扉世界数亿信徒祷告 → 信仰之力跨星门补灵，与"神力槽跳水"的成本形成收支平衡，禁止主角无限蓝条。

### 世界背景
- 地球杀场（杀场游戏）：人类历史上一切幻想作品（神话/史诗/动漫/电影/游戏）都是其他世界在地球的投影，玩家穿梭副本（诸天万界）争夺资源。
- 前五次生物大灭绝 = 前五次杀场游戏失败（第六次灭恐龙，第七次轮到人类），这是全书的世界观内核。
- 势力：特事局（官方超凡组织）、异学会、岿阳派、蜃龙、门扉世界、星界、虫群、天使军团等，各有利益诉求。
- **世界观是全球化的**：除特事局外，还有全球超自然联盟、FBI 特异事故处、德意志异常事务调查局、守望者结社等各国 / 第三方组织，各司其职、互相制衡，禁止把超凡世界写成只有主角一方。
- **国际势力博弈**：特事局 vs 中情局 / 德意志 / MI6 / 普罗米修斯实验室——西方机构下绊子、散播虚假消息、扣押华裔精英，大英博物馆掠夺的东方文物里藏超凡物品，异学会典籍流失 40%。把现实国际关系写进超凡世界（机构竞争、文物归属、科技公司当白手套），禁止把国与国写成铁板一块。
- **公会体系六分类**（官方背书 / 传承秘密结社 / 新兴秘密结社 / 有传承普通公会 / 有现世势力的公会 / 同好会），主角属于"孤狼 / 寒鸦公会"一类，靠独立发育。
- **竞技体系**：天空斗技场淘汰赛 → 五百强 → 境域回廊赛段 → 门扉争夺战，配合个人战力排行榜 + 第三方榜单（守望者结社），升级不只靠副本，还有竞技排名。
- 世界观扩展节奏：新设定必须通过主角入局 / 副本 / 遇见新角色逐步解锁，禁止一次性倾倒设定。

### 规则设定
- 世界核心规则：玩家资格可转移（击杀玩家获得资格）、副本（剧本任务）分阶段推进、完全扮演模式禁金手指、杀场游戏的本质是"战争"（文明-星球-位面-晶壁系-多元宇宙的战争磨盘）。
- 当剧情需要突破规则时，必须先铺垫规则漏洞或付出等价代价，禁止临时添加未铺垫的新规则来解围。

### 经济系统
- 资源获取必须有合理来源（副本奖励 / 游戏币 / 交易 / 猎杀掉落），禁止凭空获得。
- 涉及游戏币、经验值时必须体现换算逻辑，禁止数字混乱。

### 社会结构
- 每个势力必须有明确利益诉求（特事局维稳 / 异学会封印 / 岿阳派追求永生 / 虫群服从造物主），禁止"为反对而反对"。
- 主角加入或对抗势力必须有合理动机与导火索，禁止无因站队。
- 现实世界规则（法律、官方、社会）对主角有真实约束（主角要毁尸灭迹、装环卫工清理现场），主角不能无视规则而无后果。

## 对话风格

### 对话比例
- 对话占全文约 20%（引号内对话 2.36 万对），战斗 / 恐怖 / 解谜章节对话占比下降，日常 / 校园 / 吐槽章节可上探。
- 禁止连续超过 3 行纯对话无动作 / 心理穿插；禁止整章无对话。

### 对话风格
- 主角对话：口语化、带现代梗、带科学推理、满嘴骚话；关键时候冒出"一本正经胡说八道"的金句。
- 引导词极简到只剩"道"（全书 13670 次绝对主导），但**吐槽型引导**是玩家凶猛独有指纹：`吐槽`（219）、`嘀咕`（109）、`随口道`（12）、`随意道`（49）、`平静道`（106），靠"轻"引导定性，禁止堆"淡淡道/沉声道"式装逼金句。
- 主角吐槽现代梗落地：`犹豫就会败北`（只狼）、`贪玩蓝月广告词`、`渣渣辉`、`共产主义接班人红领巾`，梗要服务剧情、逻辑自洽。
- **古风副本 + 现代梗碰撞是招牌笑点**：武侠/古代副本里硬塞现代网络梗（"见光死的网络情侣""全明星大乱斗""九块九廉价商品店""粉色心型镶钻墨镜"），古人与现代人的认知错位制造笑点，禁止纯古代腔或纯现代腔。
- 禁止所有角色说话方式雷同；每个主要角色必须有可辨识的说话方式。

### 对话功能
- 对话必须承担功能之一：推动情节 / 暴露性格 / 传递关键信息 / 制造冲突 / 制造笑点，禁止无功能寒暄。
- 关键信息通过对话揭露时，必须有说话动机（当事人知情、被套话、显摆、审问），禁止角色无故爆料。
- 禁止角色长篇解说设定（用副本 + 叙事代替）。

### 对话长度
- 对话短促为主（中位数 9 字），偶发长独白（推理揭底、科学解说）。
- 日常对话不超过 4 轮必须插入动作 / 神态；超过 4 轮的关键对话要分段，中间穿插环境 / 动作 / 心理。
- 禁止一句话超长台词，禁止对话中夹带大段设定解说。

### 口头禅和语气词
- 语气词托底口语感：么（什么/这么/那么/怎么）/ 吧 / 啊 / 呢 / 吗 密集。
- 都市口语 + 东北腔接地气：整（2210，全书最高频口语词）/ 干 / 靠 / 浪 / 蛋疼 / 我去 / 离谱 / 老铁 / 整活，用于吐槽与日常。
- 文雅自黑而非纯脏口：蛋疼（82）/ 二货 / 智障 / 扯淡 / 傻子，卧槽仅 23 次，禁止让高中生主角满嘴纯脏口。
- 主角推理口头禅：`可能`（2360）/ `那么` / `也就是说`，用于展开推理链时。
- 禁止所有角色共用同一口头禅；口头禅每章同一角色不超过 3 次。

## 描写风格

### 环境描写
- 新场景首次登场必须白描环境（凶案现场 / 鬼打墙楼道 / 副本密室 / 校园），环境必须服务于氛围（压迫 / 阴森 / 市井）。
- 单次环境描写不超过 80 字，必须含至少 1 个感官细节（光线 / 声音 / 温度 / 血腥味）。
- 恐怖氛围靠细节（尸斑、人面猫、干涸血迹、腐烂气味）而非直述"很恐怖"。
- **无解灵异的"色彩剥夺式"氛围**：极致恐怖靠"剥夺"——整个世界灰蒙蒙没有颜色、唯一有颜色的是一栋孤楼、灵视都看不清五米外（"整个世界像是被剥夺走了所有色彩"），用"看得见的东西变少"制造窒息感，禁止靠堆血浆制造恐怖。
- 禁止用环境描写凑字数，禁止环境与当前情绪氛围矛盾。

### 心理描写
- 主角面临谜题 / 重大决策 / 绝境时必须写心理，用内心吐槽 + 行为暗示结合，禁止纯内心独白超 100 字。
- 战斗中不写长心理，只用短句闪念；日常允许深入吐槽。
- 情绪外化优先用极短肢体微反应（挑眉 / 眉头微皱 / 一挑眉梢 / 眼角一抽 / 撇了撇嘴）替代心理直述，把情绪压进一个动作。

### 战斗描写
- 重要战斗（涉及主角 / 关键剧情）必须详细写招式与等级差距；过场战斗一笔带过。
- 每 3~4 个动作必须插入一次拟声词或旁观者反应，禁止纯动作堆砌。
- 胜负必须有逻辑支撑（等级 / 策略 / 道具 / 状态 / 反套路），禁止"因为主角所以赢"。
- 拟声词制造临场感：轰 / 砰 / 咔 / 啪 / 咚 / 咔嚓 / 呲（现代都市 + 枪炮 + 机械）。
- 战斗要"拳拳到骨"的暴力美学，禁止光波对轰、抽象斗法（原书后期虫族大战被诟病"口嗨"，仿写时保持前期实感）。
- **宏观尺度战争要有微观锚点**：虫群 vs 巨人免疫系统的战争（"星球般巨人体内"），宏大设定必须用微观细节落地——溶酶体酶腐蚀、微绒毛切割、巨噬细胞触须回收、透过半透明细胞膜看见溶解的兵虫，禁止只写"百万大军对冲"的空镜头。
- **游戏外挂可以战斗化**：境域回廊绝地求生局里，特事局给玩家上"外挂"（超级瞄准/十米金身），对手用"红太狼挂"平底锅挡子弹——游戏文化（外挂/开黑/作弊）变成超自然战斗手段，把严肃战场戏谑成"神仙打架"，这是游戏化叙述的极端形态。
- **身体恐怖（body horror）**：克苏鲁式的血肉异变是本书恐怖底子——人面猫披人皮、人鬼合体时"眼睛里长出耳朵，鼻孔里长出手指，牙关里冒头发"，畸变器官（重瞳眼球/肿瘤脑组织/增殖手指）收藏在玻璃瓶里。恐怖场景允许用"身体结构错乱"制造不适感，但必须克制，禁止为恶心而恶心。

### 情感描写
- 用行为和细节暗示情感，禁止直接写"他很伤心 / 她很感动"。
- 情感爆发（牺牲、离别、人性锚点）前必须有压抑铺垫，禁止突然煽情。
- 男女情感落"斗智斗勇 + 留白"，禁直白告白式煽情；恐怖/黑暗情感要落到"人性锚点"（王丛珊）的拉扯上。
- **李昂 × 王丛珊的斗嘴模式**：男方整活、女方吐槽，双向默契才是感情升温的方式——李昂一本正经地"超度仪式"（大悲咒 + 哭丧录音 + 白孝帽 + 遗照果盘），王丛珊翻白眼（"合理个头，明明就是阴间项目""能不能整点阳间的活"），李昂玩双关（真拿小太阳取暖器 = "阳间的活"）。禁止直白告白、禁止腻歪情话，感情藏在"整活与吐槽"的往返里。

### 感官描写
- 视觉 + 听觉为基本（拟声词密集），恐怖 / 战斗场景必须加入触觉（冷 / 冰 / 痛 / 麻）与嗅觉（腥 / 臭 / 腐臭）。
- 味觉明显弱化，可选择性补足但非必要。
- 禁止仅用视觉描写，禁止感官与场景不匹配。

## 题材专项能力

### 副本解谜流设计
- 每个副本必须有一个"规则"或"谜题"：主角靠高智商推理 + 反套路操作拆解（鬼打墙爬楼、鲸落推理、逆流蜉蝣密室）。
- 副本结构三步走：① 系统发布任务（面板【】）；② 主角做观察、列可能性、逐一排除；③ 用一条被忽略的细节翻盘。
- 关键：主角解密必须把推理过程**摊开给读者看**（"现在有四种可能性……"），让读者同步推理，禁止主角藏着答案到结尾才揭。
- 副本必须"串本"：一个小副本牵扯出背后的大局，禁止孤立的单元副本。
- 副本题材包罗万象：现实 / 平行世界 / 古今中外 / 奇谈怪论 / 童话 / 异世界 / 数码世界 / 高维界面，前中期以恐怖 + 推理为主。
- **民俗灵异副本是特色**（红白双煞 / 百鬼夜行 / 借阳寿成亲）：用民俗禁忌（红白冲撞、鬼笑、仪式借寿）做恐怖底子，再靠主角的"科学祛魅 + 沙雕搅局"破解，禁止纯吓人不解谜、也禁止纯搞笑不吓人。
- **恐怖分两类（无解灵异 vs 可沟通恶灵）**：非理性灵异（"怪异"，无法沟通、像固定在事物上的自然现象，如《咒怨》）与恶灵（有人类记忆情绪，可谈判、可利用）。两类副本的解法不同——恶灵副本可以谈判合作（孤寒寺柴翠翘），无解灵异只能靠推理与苟活（海豚酒店），禁止混为一谈。
- **多人副本的猜疑博弈**：14 名玩家同进一个副本、禁召唤物、友军伤害屏蔽关闭（玩家可互相残杀），玩家间先互相提防、再被迫合作。此时李昂的沙雕骚话承担"破冰"功能（用"十四位至尊，一念花开，君临天下"的中二配音化解对峙），禁止把多人副本写成一条心打怪。

### 马甲 / 身份错位设计
- 主角靠马甲在副本里周旋：每个马甲要有明确用途（西门子道人=招摇钓鱼引蛇出洞、书生=低调潜伏、危月燕=武力掩护）。
- 马甲之间要有"招摇 vs 低调"的反差，且主角对"玩身份"有恶趣味（用幻术改五官成毕加索脸、给自己起"西门子"这种逗比代号）。
- 幻术 / 幻象是马甲的技术支撑：主角用幻术制造分身、误导敌人、控制 NPC（引赞鬼魂），但幻象"远距离逼真、接近即穿帮"，有明确弱点。
- **马甲的战术功能是"身份切割"**：李昂用"李日升"马甲 + 召唤术·恐惧战马，把自己伪装成"第二梯队召唤玩家"，与虫巢划清界限（虫巢规模太大，绝不能让人知道受某玩家控制）——马甲不只是恶趣味，更是战略伪装，每个马甲都要回答"它在掩护什么"。
- 禁止马甲只是换名字无实质作用，每个马甲都要推进剧情或制造笑点。

### 沙雕骚话流设计
- 骚话必须"玩梗 + 逻辑自洽"双赢：`"犹豫，就会败北"`既是只狼梗，又推进了"站着不动最糟"的判断。
- 一本正经胡说八道：用科学知识（鲸落 / 病理 / 概率 / 基因）一本正经解释荒谬，爽点落在"严谨与荒谬的反差"。
- 骚话要克制：每个梗服务剧情，禁止为了玩梗而玩梗、堆砌网络段子。
- 反套路操作：主角用意外手段解决问题（用十叠蚊香熏队友、把家访老师带到垃圾堆），爽点落在读者意外感。
- **广告词 / 口号梗**也是骚话库的一部分：`"透心凉，心飞扬"`（雪碧）、`"八荣八耻、社会主义核心价值观"`对鬼喊话、`"犹豫，就会败北"`（只狼），现代口号与恐怖/古代场景的错位制造笑点。
- **中二配音破冰**：多人对峙僵局时，李昂用苍劲雄浑的声线给现场"配音"（"十四位至尊，一念花开，君临天下，镇压世间一切敌"），把剑拔弩张的气氛搅成闹剧——沙雕骚话有"破冰/解围"的功能，禁止为搞笑而搞笑、不解决任何问题。

### 鬼魂合作流设计（孤寒寺模式）
- 恶灵副本可以"谈判合作"：给厉鬼一个完整悲剧背景（柴翠翘：明代官宦庶女，许配龙阳之好的贾二公子，孤寒寺求子被淫僧害死，怨气成厉鬼），让"鬼"有动机、有诉求、有弱点。
- 合作谈判必须双向算计：李昂用"情况一 / 情况二 / 情况三"逐条权衡利弊再决定合作，鬼也有自己的盘算（藏进李昂体内既隐匿身份又当人质），禁止主角无脑信鬼。
- 合作必须有反制手段：李昂让鬼上身的同时用猫眼幻术暗中定住对方（"俯身可以，但是必须有反制的手段"），禁止主角把命门交给鬼。
- 鬼的悲剧背景要克制：用事实白描（被砍成几截、埋在后山、家人拒认遗骨），禁止大段煽情。

### 科学降维设计
- 主角的"高智商"不是灵光一现，而是把科学方法用到荒谬处：开篇用"鲸落理论"破案，副本里"摸牙齿、测身高、干呕看内容物"判断身体归属。
- 科学解释必须通俗可懂（视杆细胞 4:1 vs 猫 25:1），禁止堆砌术语让读者晦涩。
- 科学与怪谈碰撞时必须"逻辑自洽"（作者自己透露前期模仿三渣《惊悚乐园》的揭秘叙述方式），禁止为搞笑牺牲逻辑。

### 系统面板设计
- 系统面板【】必须克制：任务目标 / 时间限制 / 奖励 / 惩罚，禁止用面板长篇倾倒设定。
- 面板刷屏要配合主角的反应（"这么灵？""这么快就来通知了么"），禁止面板单独成段无互动。
- 完全扮演模式是"封金手指逼智斗"的利器：无属性强化、无物品栏，逼主角纯靠脑子解密。
