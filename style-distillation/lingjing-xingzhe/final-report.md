## 四、五大叙事模型（v2 提出，七版保持）

### 1. 规则类怪谈副本制
核心冲突不是"打怪"，而是"读规则、破规则"。每个副本是自带规则手册的封闭空间，规则荒谬却自洽，违反即死。
- 写法：先立自洽规则（能做什么/不能做什么/违反代价），主角靠观察、试探、犯错、修正摸清并利用规则。
- 破解三步走：① 摸清规则（用人命/道具试错，或主动找员工手册、遗书、记忆碎片）；② 找漏洞（"是规则皆有漏洞"）；③ 用漏洞反杀。规则本身可以是武器。
- **v7 补充**：规则类道具的规则"连道具本身都不能改"；规则多是"注意事项"而非"解法"，触发即死路，主角靠钻空子而非读全手册。
- 边界：规则必须前后自洽、可被读者推导，否则是"作者说了算"的降神。

### 2. 市井烟火 × 诡异侵入（双重底色切换）
日常戏（催婚、早餐、麻将、捏脚、毒舌互怼）与诡异副本戏交替。日常立人设、松节奏、埋关系钩子；副本做压迫感、推理、爽点。诡异事件常从熟悉环境悄然侵入。
- 边界：日常戏不能纯水，每段都要埋钩子或推进关系。

### 3. 推理外化（把脑内演算摊给读者）
主角的怀疑、复盘、假设、验证全部以口语化内心独白外化，读者与主角信息同步，跟着一起推。判断词密集（不是/就是/可能/只能），推理裹着吐槽，不论文。
- 边界：不能变成机械列清单；推理要有可验证依据，禁止"灵光一现"。

### 4. 马甲与身份错位（多身份驱动的爽点与伏笔）
主角持多重身份（现实/灵境/隐藏底牌/卧底马甲），不同圈层被不同认知，制造错位爽点与信息差，作超长线伏笔后期引爆。
- 边界：揭底必须有前期可查铺垫；马甲数量可控，避免身份混乱。

### 5. 时间循环 / 自我成全的伏笔回收（闭合式因果）
过去某一关键谜团的始作俑者，正是穿越回去的主角本人（"原来是我自己"），形成自我成全的闭合因果。
- 硬约束：① 次数/代价有限（"只能回到过去、共 4 次、用力量越强耗损越大"）；② 时间跳跃必须用明确道具/动作标记（电子表表盘逆转），禁止无提示跳转；③ 闭环必须能回头查证早埋的蛛丝马迹。

**母题意象**（贯穿全书）：圆月/月华（灵境入口标记与副本恒定环境光）· 规则/手册（枷锁也是武器）· 名字/身份（忘名即失格）· 污染/黑化（身体侵蚀异化成怪物，v7 扩展含"性格黑化"）· 意难平（牺牲离别作情绪高点）。

## 七、世界观设定（最终版）

### 灵境本质
依附现实的超自然子空间，本质是神灵创造的"游戏服务器"，用于催化灵境行者成长、挑选"管理员"对抗阴性神灵（入侵者）。核心闭环：角色卡 → 职业 → 灵境副本 → 道德值。

### 力量体系
- 等级 1-9 级三阶：超凡境（1-3）、圣者境（4-6）、主宰境（7-9）；主宰之上为半神/至高，终极是"三道合一"的灵境之主。
- 职业分守序（夜游神、日游神、星官、斥候/剑客/偃师、火师、水鬼、木妖、巫蛊师、蛊惑之妖、雾主、学士、幻术师/掌梦使等）与邪恶（绝命毒师、酗酒者、爱欲职业等）；有转职/进化树（夜游神 → 星官 → 太阳之主 → 灵境之主）。
- 高阶战斗规则：九级主宰接近天花板，层次越高越难越级；"技近乎道"的传承者（古代修行者、单传骑士）能越级碾压；规则类道具到九级"没那么好用"（九级已触及规则之力）。
- 古代修行者另有体系（土怪、山神、日游神、金乌），"技"的磨砺远强于现代行者。
- 等级决定副本难度，灵境有平衡匹配机制；跨级战斗必须有道具/地利/对手状态解释。

### 道具体系（三类）
- 代价类：有使用代价（能源、灵力、次数），禁无限续航。
- 规则类：最高阶、最难收服，收服方式是"找到规律、破解规则"；能力有极限（红舞鞋闪避有上限、九级失效）。代表：员工手册、圣婴（哭声让人怀孕，堵嘴即破）、母神子宫（复活）、河伯印（克雾）、电子表（穿梭时光）。
- 高阶不明类：主宰级武器（形神俱灭刀、寒铁玉龙剑）、本源碎片、光明罗盘碎片。
- 呈现格式：属性面板（【名称】【类型】【功能】【介绍】【备注1/2/3】），规则限制写在备注里。

### 世界规则
- 道德值初始 60：做坏事扣分、做好事加分，低于阈值被清除。
- 灵境随机分配角色卡+任务，危险越大收获越大；非灵境物品不可带入（药品必须已服用才可带入）。
- 晋升圣者/主宰须参加年中和年尾的大型杀戮副本；角色卡死后可被"交易/传承"截留（权柄交易）。
- **灵境通缉机制**：越强大的行者在现实越克制——被通缉会成为"位置实时播报的公敌"，正邪群起攻之；所以主宰级在现实不敢轻易出手、不敢在闹市动手。
- 高阶强者也有代价：强杀国师触发"天人五衰"（印堂发黑、气血衰败）、敲鼓续战七窍流血。
- 突破规则必须先铺垫漏洞或付出等价代价，禁临时添加未铺垫的新规则解围，禁主角无条件规则豁免。

### 阵营与势力
- 守序：五行盟（赤火帮、水神宫、百花会等五大帮派结盟）、太一门、灵境世家、猎人公会、天罚组织（三权分立：执行官/检察官/董事会）；邪恶：三大邪恶组织、自由盟约、散修。
- 层级：队员 → 队长（什长）→ 执事 → 长老 → 盟主。
- 每个势力必须有明确利益诉求（养蛊式培养后辈/维持规则/攫取本源/培养太阳之主），禁"为反对而反对"。
- 阵营冲突宏观推手：太阳之主归属决定阵营胜负，故双方决战前互相削弱、抢培养己方太阳之主。
- 扩展节奏：新设定必须通过主角进入新副本/遇见新角色逐步解锁（灵境三大区、光明罗盘预言、日月星本源、夜游神特殊、高天原/三大神器分批释放），禁一次性倾倒。

## 八、对话与描写风格

### 对话
- 对话驱动（占全文约 27%），短促对话为主（中位 12 字），偶发长独白。
- 引导词极简到"道"，靠前置神态/动作/声调定性：装逼用"淡"、压场用"沉"、轻松用"笑"、对峙用"冷"。
- 禁止连续 3 行纯对话无动作/心理穿插；群聊/会议可推进剧情（白虎卫群聊、五行盟长老会）但每 3 轮必须插入动作/心理/神态；禁止整章无对话。
- 说话方式是设定的外化，每个主要角色有可辨识的用词/句式/语气词；禁所有角色说话雷同。
- 对话必须承担功能（推动情节/暴露性格/传递信息/制造冲突）；关键信息爆料必须有说话动机；禁长篇解说设定。
- 口头禅每章同一角色不超过 3 次；粗口用于吐槽与日常，禁用于正式对峙的主角台词。

### 描写
- **微反应外化情绪**：一愣/一僵/一顿/耸肩/挑眉/咧嘴/撇嘴/皱了皱眉，情绪压进一个动作，一句带过；禁大段心理独白（主角推理过程除外）。
- **五感**：视觉+听觉双主导（拟声词啪/砰/轰/咚/咔/嗡/噗/嘣/duang/吱/咻密集），触觉次之，嗅味觉弱化；禁仅用视觉描写。
- **恐怖感**：环境白描 + 主角生理反应（冷汗、鸡皮疙瘩、心跳、头皮发麻），禁直述"很恐怖"。
- **环境**：新场景首次登场必须白描（荒废小楼、黑洞洞窗户、昏黄路灯）；单次不超过 80 字且含至少 1 个感官细节；环境必须服务氛围，禁凑字数、禁与情绪矛盾。
- **内心吐槽**：心说/腹诽高频，带网络梗（"小黑子，终于露出鸡脚了""你个老六""企业级理解""996福报不算"），推理裹着吐槽。
- **战斗**：重要战斗详写招式、位格差距、道具切换，过场一笔带过；每 3-4 个动作插入一次拟声词或旁观者反应；心理战与正面战并重（强敌先攻心：赌约、震慑、动摇军心）；胜负必须有逻辑支撑（实力/策略/道具/状态/代价），禁"因为主角所以赢"。
- **情感**：用行为和细节暗示，禁直写"他很伤心"；情感爆发前必须有压抑铺垫；男女落"撩而不点破"。

### 叙事结构硬规则
- 第三人称限知，POV 锁定主角；每章至少 2 个事件推进点（关系变化/信息揭露/危机升级/规则破解）；禁连续 3 段纯描写无事件。
- **POV 例外**（v6 起）：为制造压迫感/群像，允许短暂切到反派/配角观察线（魔眼天王追查、拓跋光赫攻心、凯瑟琳读报告、魏元洲弑亲独白），切换后用"场景空镜/时间标"过渡，禁同一场景内来回跳。
- 每章结尾必须留"异动钩子"（物件自动、远处呼唤、一句反常的话、未解疑点、新马甲/新危机登场），禁平静收束。
- 卷/篇收尾回收该卷主要伏笔（至少 80%），同时为下一卷埋新矛盾；全书收束：身份与伏笔闭环回收 + 阵营胜负落定，落回情感余韵或世界观余白。
- 开篇套路：第一章"家庭日常+一件怪事"双线开局（催起床、小姨相亲、早餐互怼 → 神秘黑卡/死党失踪）；第 1 章 2000 字内必须出现怪事钩子；悬念随章递进（黑卡凭空消失 → 死党整晚没出寝室却失踪 → 调查员上门，层层收紧）。
- 超长线伏笔（神秘寄件人、投资人、隐藏身份、时间闭环、被诅咒的黑化）跨数百章，结尾回收成"原来是我自己/原来是你"式闭合因果，前期必须留可查线索（魔君是舅舅的"试验品"、婉美人是太后死士、母神子宫复活、魔眼的诅咒）。

## 九、不可写（七条硬禁忌）

1. 绝不用"说"字堆形容词，一律"道"+前置神态，不写"激动地说、悲伤地说"。
2. 绝不把女性写得露骨直白，不写性行为细节，福利落在神态、氛围与留白。
3. 绝不让主角的推理藏在幕后或由旁白代答，推理必须外化、可被读者跟推。
4. 绝不用碎句连排的短剧腔，要长短呼吸、长句做描写。
5. 绝不堆书面化套话与 AI 式逻辑连接词，拒绝"一方面……另一方面……"的论文腔。
6. 绝不凭空降神破局，规则破解必须有前期可查的规则线索支撑。
7. **绝不用破折号（个人偏好，高于原文统计）。**

## 十、作者人格（PART B，最终收敛）

### Layer 0 核心性格（最高优先级）
- 商业性与文学性并重：网文第一性是让读者"好看"，但绝不停留在纯爽文（"不能只是纯爽文，不然就沦为下乘了"），每个故事要有精神内核，主角在大是大非前有坚守。
- 市井烟火气托底：接地气、爱玩梗、诙谐吐槽，再严肃的悬疑也掺进轻松吐槽（"人性的扭曲还是道德的沦丧""企业级理解"）。

## 十一、历史修正与遗留问题

### 本次整合修正的三处问题

1. **作者归属错误（重要）**：v2、v4、v5、v6、v7 的"诚实边界"均写"《玩家凶猛》属卖报小郎君另一套题材与笔法"——**错误**。《玩家凶猛》作者是黑灯夏火（阅文 LV.5），不是卖报小郎君。卖报小郎君本人作品为《原来我是妖二代》《大奉打更人》《灵境行者》。《玩家凶猛》只能作为"外部参考风格"引用，不能挂在卖报名下。本报告已全部剔除该错误表述。
2. **力量体系表述冲突**：v3 写"夜游神 → 星官 → 太阳之主 → 灵境之主"，v4 写"夜游神 → 日游神 → 主宰境 → 灵境之主"（把职业转职树与位格阶梯混淆）。v5 起收敛为完整体系：1-9 级三阶 + 转职树（夜游神 → 星官 → 太阳之主 → 灵境之主）。本报告采用收敛后的最终口径。
3. **章节口径差异**：v1 统计口径 1035 章/429.5 万字（含标点，含请假条等全部章节条目），v4 起正文口径 1020 章/417.9 万字（起点官方，剔除非正文）。词频数字出自 v1 全量统计，两口径并存不冲突，使用时注明口径即可。

### 诚实边界（沿用）
- 本报告只基于单本《灵境行者》，不能代表卖报小郎君全部创作阶段（《大奉打更人》属另一套题材笔法，另有独立文风skill）。

- 规则类怪谈、时间闭环、荒诞破局、推凶反转、阵营信息差、主角黑化等是《灵境行者》的强辨识度特征，换到作者其他题材或他人作品未必适用，需按场景取舍。
- 作者人格 Layer 4（互动行为）大部分标注〔不足〕，不编造。

### 遗留问题
