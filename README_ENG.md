# novel-craft-lab

A methodology lab for AI-assisted web-novel writing: a chapter-pipeline SOP, scriptable red-line QA tooling, and postmortems of a style-distillation pipeline that never shipped.

> Only methodology and tooling are published. The author's own novel drafts, outlines and settings are **not** part of this repository; corpus of the distilled works is likewise excluded.

## Contents

- `methodology/` — chapter pipeline SOP, a 50-item danger checklist with G0-G6 gates, writing calibration, paired before/after analysis, an opening-structure case study
- `tools/` — red-line wordlist + scanner, AI-fingerprint / structure / emotion analyzers, preference-sample template
- `style-distillation/` — final SKILL.md + seven-round postmortem reports for three published works (rules and statistics only; short quotations kept for analysis)

Docs are written in Chinese; an English translation is welcome as a PR.
