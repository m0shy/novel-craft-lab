# 偏好样本库

> 用法：每章归档时，从"AI 原稿 vs 我的终稿"中挑 1-3 个典型差异段录入。攒 300+ 对启动 FTPO（偏好优化训练法：用"AI 原稿 vs 人工终稿"的成对样本微调模型，让输出向人的写法靠拢）；同时作为范文锚（放进生成上下文供逐句对照的样板段落）的轮换素材池。

## 录入格式

```
### #编号 | 日期 | 第N章 | 类型(文风/剧情/人设/审核)
【AI 原稿】……
【我的终稿】……
【为什么】一句话（修订注里的理由）
```
